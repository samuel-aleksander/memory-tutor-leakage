Each bar splits one cell's dialogues by the highest level they reached in 5 turns. Click a cell to read its dialogues.

When does it leak?

Dialogues that had reached at least this level by each turn. Fractions, not percentages: the cells are small.

    How much code was handed out?

    New code lines the tutor wrote in code blocks at each turn, and in the whole dialogue, averaged over each cell's dialogues (hover a cell for each dialogue's value). Counted by rule, not by an LLM. Lines already shown, comments, docstrings, imports, def lines, the task's own stub, lines that hand out nothing (pass, ..., a bare ___ blank), hand-traced walkthroughs and code for a different function don't count; control flow like continue or return result does. For scale: a full direct leak of HumanEval/1 comes to about 12–19 lines. Code written inline in the prose isn't counted.
